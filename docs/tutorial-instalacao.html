Visão geral

Os PDFs ficam no servidor; o Supabase fornece autenticação e banco de dados. A integração com WhatsApp é opcional.

0

Antes de começar

Tenha os acessos e dados necessários à mão.

ServidorUmbrel OS com Docker e acesso SSH.
Contas e dadosSupabase, e-mail do administrador e endereço público do portal.

Não coloque arquivos de ambiente no Git. A chave SUPABASE_SERVICE_ROLE_KEY dá acesso administrativo ao banco; mantenha-a somente no servidor.

1

Prepare o Supabase

Crie o banco e aplique as tabelas e regras de acesso.

  1. Crie um projeto no painel Supabase.
  2. Abra SQL Editor e execute o conteúdo de supabase-schema.sql deste repositório.
  3. Em Project Settings → API, copie a Project URL, a chave pública anon e a chave secreta service role.

Confira: as tabelas magazines, settings e logs_whatsapp aparecem no Table Editor.

A chave service role nunca deve ir para o navegador ou para o Git. Guarde-a somente no arquivo de ambiente do servidor.

2

Crie a conta administradora

O painel exige o papel seguro app_metadata.role.

  1. Em Authentication → Users, crie um usuário com e-mail e senha.
  2. Copie o UUID do usuário.
  3. Em um ambiente confiável no servidor, use a Admin API do Supabase para atribuir app_metadata.role = "admin" ao UUID.
  4. Saia da sessão e entre novamente para receber as permissões atualizadas.
Admin API · exemplo servidor
await supabase.auth.admin.updateUserById("UUID-DO-USUARIO", {
  app_metadata: { role: "admin" }
});

Faça essa chamada somente no servidor, com a service role. Não use user_metadata para conceder acesso: o próprio usuário pode alterá-lo. Referência oficial da Admin API ↗

3

Configure o arquivo .env

Conecte ao Umbrel e crie o ambiente local do servidor.

SSH · terminal do seu computador
ssh umbrel@umbrel.local
cd ~/ebd-revista-manager
cp .env.example .env
nano .env

Preencha as variáveis principais:

.env · valores ilustrativos
NEXT_PUBLIC_SUPABASE_URL=https://SEU-PROJETO.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=SUA_CHAVE_ANON
SUPABASE_SERVICE_ROLE_KEY=SUA_CHAVE_SERVICE_ROLE
NEXT_PUBLIC_APP_URL=http://umbrel.local:3000
UPLOAD_DIR=/app/data/uploads
PORT=3000
CRON_SECRET=GERE_UM_SEGREDO_FORTE
WHATSAPP_PROVIDER=evolution
WHATSAPP_API_URL=http://evolution-api:8080
WHATSAPP_API_KEY=GERE_UMA_CHAVE_FORTE
WHATSAPP_INSTANCE=pib-cataguases-ebd
WHATSAPP_GROUP_JID=ID_DO_GRUPO@g.us

Gere segredos diferentes com openssl rand -hex 32. A chave WHATSAPP_API_KEY precisa ser igual na Evolution API e no app. Substitua a URL pública se usar domínio próprio.

Salve no Nano com Ctrl+O, Enter e saia com Ctrl+X. O .env é ignorado pelo Git.

4

Instale e inicie a aplicação

O Docker compila o portal e inicia os serviços configurados.

Umbrel · pasta do projeto
chmod +x scripts/init.sh
./scripts/init.sh
docker compose up -d --build

Confira o estado e os logs:

Verificação
docker compose ps
docker compose logs -f ebd-app

Abra http://umbrel.local:3000. O painel fica em /admin/login.

A porta da Evolution API está disponível apenas no próprio Umbrel; não a exponha diretamente à internet.

5

Conecte o WhatsApp (opcional)

Crie uma instância e faça o pareamento pelo QR Code.

Primeiro, abra um túnel SSH no computador e mantenha essa janela aberta:

Terminal local
ssh -L 8080:127.0.0.1:8080 umbrel@umbrel.local

Crie a instância a partir do Umbrel usando a chave definida no .env:

Terminal do Umbrel
curl -X POST http://localhost:8080/instance/create \
  -H "apikey: SUA_WHATSAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"instanceName":"pib-cataguases-ebd","token":"SUA_WHATSAPP_API_KEY","qrcode":true}'

Com o túnel ativo, abra localhost:8080/instance/connect/pib-cataguases-ebd e leia o QR com o celular da igreja.

No painel, abra Configurações, informe o JID e use Testar conexão. Revise destinatário e mensagem antes de habilitar disparos automáticos.

6

Faça a primeira publicação

Confirme cada parte do fluxo antes de divulgar o portal.

  • Entre com o usuário administrador em /admin/login.
  • Envie um PDF válido de até 25 MB em Nova Revista.
  • Confira título, data da lição e horário de publicação.
  • Teste a visualização e o download no portal público.
  • Habilite WhatsApp só depois de validar grupo e mensagem.

Ajuda rápida

O login não abre o painel

Confirme que o usuário recebeu app_metadata.role = admin e entre novamente para renovar a sessão.

O Supabase não conecta

Revise as três credenciais no .env. Depois da alteração, aplique docker compose up -d --build.

O QR Code não abre

Mantenha o túnel SSH ativo e confirme o container com docker compose ps.

O upload falha

Confira espaço em disco, o limite de 25 MB para PDF e os logs do app.

Como atualizar?

Faça backup do .env e da pasta data/uploads; atualize o código e reconstrua os containers.
