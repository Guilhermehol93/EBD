Seção 01

1. Visão Geral do EBD Revista Manager

O EBD Revista Manager foi desenvolvido para a Escola Bíblica Dominical da Primeira Igreja Batista de Cataguases. Ele resolve de forma simples, automatizada e com custo zero a distribuição semanal das lições e revistas para os membros da igreja.

Armazenamento Local

Todos os arquivos PDF e imagens de banner são armazenados no volume persistente do servidor Umbrel, eliminando custos de S3 ou Supabase Storage.

Agendamento & WhatsApp

Faça o upload na segunda ou terça-feira e programe a publicação para o domingo às 08:00h com disparo automático para o grupo da igreja.

Leitor Online Embutido

Os membros podem ler a revista direto no celular através do visualizador web ou baixar o arquivo em PDF com apenas um toque.

Seção 02

2. Requisitos Prévios

  • ✔ Servidor Local Umbrel OS: Qualquer computador com Umbrel OS instalado e acesso via terminal SSH.
  • ✔ Docker & Docker Compose: Já inclusos nativamente no Umbrel OS.
  • ✔ Conta Gratuita no Supabase: Projeto gratuito em supabase.com utilizado exclusivamente para autenticação e metadados.
  • ✔ WhatsApp para Conexão: Um aparelho ou chip para ler o QR Code da Evolution API.
Seção 03

3. Configuração do Supabase (Banco & Auth)

Siga os passos abaixo para configurar o banco de dados em menos de 3 minutos:

  1. Acesse o painel do seu projeto no Supabase: https://supabase.com/dashboard.
  2. No menu lateral esquerdo, clique em SQL Editor.
  3. Clique em + New query.
  4. Abra o arquivo supabase-schema.sql existente na raiz deste repositório, copie todo o conteúdo e cole no editor.
  5. Clique no botão verde Run. A estrutura de tabelas, índices e políticas de segurança será criada instantaneamente.
  6. No menu Authentication > Users, clique em Add user > Create user e crie o usuário e senha do administrador (ex: admin@pibcataguases.com.br).
  7. Vá em Project Settings > API e copie:
    • Project URL -> NEXT_PUBLIC_SUPABASE_URL
    • anon public key -> NEXT_PUBLIC_SUPABASE_ANON_KEY
    • service_role secret -> SUPABASE_SERVICE_ROLE_KEY
Seção 04

4. Guia Passo a Passo no Umbrel OS (via Repositório GitHub)

Execute os comandos abaixo no terminal SSH do seu servidor Umbrel OS:

Passo 4.1: Conectar via SSH no Umbrel

ssh umbrel@umbrel.local

Passo 4.2: Clonar o Repositório do GitHub

cd ~
git clone https://github.com/SEU_USUARIO/ebd-revista-manager.git
cd ebd-revista-manager

Passo 4.3: Criar e Configurar o arquivo .env

cp .env.example .env
nano .env

Preencha suas chaves do Supabase e salve com Ctrl + O e saia com Ctrl + X.

Passo 4.4: Executar Script de Inicialização

chmod +x scripts/init.sh
./scripts/init.sh

Passo 4.5: Subir os Containers Docker

docker compose up -d --build
🎉 Pronto! A aplicação estará acessível na sua rede local em:
http://umbrel.local:3000 ou pelo IP local da sua máquina.
Seção 05

5. Automação do WhatsApp (Evolution API)

O arquivo docker-compose.yml já inclui o serviço da Evolution API v2 rodando na porta 8080 de forma 100% self-hosted.

Como conectar o WhatsApp:

  1. Crie a instância na Evolution API via curl ou painel da Evolution: 
    curl -X POST http://localhost:8080/instance/create \
  -H "apikey: ebd_evolution_cataguases_key_2026" \
  -H "Content-Type: application/json" \
  -d '{"instanceName": "pib-cataguases-ebd", "token": "ebd_evolution_cataguases_key_2026", "qrcode": true}'
  2. Obtenha o QR Code na rota: http://umbrel.local:8080/instance/connect/pib-cataguases-ebd
  3. Abra o WhatsApp no celular > Aparelhos conectados > Conectar um aparelho e aponte para a tela.
  4. No Painel de Administração da EBD em Configurações, preencha o JID do grupo e clique em Testar Conexão!
Seção 06

6. Manual Completo do Administrador

Como fazer Upload e Agendamento:

1. Acesse /admin/login e entre com suas credenciais.

2. Clique no botão Upload de Nova Revista.

3. Arraste o arquivo PDF da lição semanal.

4. Preencha o Título, Trimestre, Número da Lição e a Data do Domingo.

5. Defina a Data e Hora exata de liberação pública (o sistema sugere automaticamente o próximo domingo às 08:00h).

6. Mantenha a opção de Disparo Agendado Ativo para que o robô envie a mensagem no WhatsApp no momento exato da liberação.

Personalização de Banners e Redes Sociais:

No menu Configurações & Banner, você pode alterar o título do banner principal, subir uma foto personalizada dos membros ou fachada da igreja e atualizar os links do Instagram, YouTube, Facebook e Grupo do WhatsApp.

Seção 07

7. Manual da Interface Pública (Usuário)

A interface pública não requer login nem cadastro. É rápida, responsiva e adaptada para celulares:

  • 📖 Ler Revista Online: Abre o leitor imersivo em tela cheia com rolagem suave página por página.
  • ⬇️ Baixar PDF: Salva o arquivo original diretamente no dispositivo do aluno.
  • 🔍 Arquivo de Lições: Permite buscar lições anteriores por palavra-chave ou número da aula.
  • 📲 Entrar no Grupo do WhatsApp: Botão de um toque para convidar novos membros para a comunidade da PIB Cataguases.
Seção 08

8. Resolução de Problemas Comuns (Troubleshooting)

Erro: "Arquivo PDF não encontrado no servidor"

Verifique se o volume ./data/uploads está com permissões adequadas executando chmod -R 777 data/uploads no servidor.

O WhatsApp não disparou no horário

Acesse Logs do WhatsApp no painel de administração e clique no botão Forçar Verificação de Agendados Agora. Se a Evolution API tiver desconectado, basta reler o QR Code.

Como atualizar o software com novas versões do GitHub?

git pull origin main
docker compose up -d --build
